## 呈現契約

1. 新圖保持原版構圖、朝向、服色及劍勢，採批准 B 的手繪古風。每個原版動作分別對應透明 PNG，原始 bytes 與提示保留；不得把一張站姿重複填入全部步態。
2. 主機分開保存底圖所有權與主角所有權。已知主角遮罩入口只有在整個 64×25 背景均可重建、完整原版記錄指紋及尺寸吻合時啟用；缺背景、未知遮罩或來源維持原版。
3. 實際遮罩 byte 寫入才建立相應主角覆繪範圍。已知主角保留其下底圖以抹除原版身形，再合成新 PNG；不能將舊原版身形留在新人物透明區。PNG 的透明背景可有與原版不同的細部輪廓，但不得影響客體碰撞或事件。
4. 不透明背景、未知繪圖、文字、頁搬移、同值覆寫及模式切換須同步更新兩層。未知角色仍依原版第六組遮罩，不能憑相同表頭冒用主角。
5. 圖像仍先於 Noto，主角透明 PNG 用預乘 alpha 雙線性取樣，採整張畫布與原比例，不能對邊漸混。任何新 PNG 損壞須原子拒用圖像組，保留 Noto。

`terrain.json` 新增 `actors`，每筆沿用 PNG 的檔名、SHA、實際尺寸及提示欄位，`source_index=72+frame`，範圍 72–83。只允許完整畫布 `sampling=bitmap`，禁止裁切及重複索引；新來源另存完整 1204-byte 指紋，不能只比前四色平面便忽略變動的遮罩。有 actors 的目錄新增十二筆原版識別，不宣稱它們都有新圖；舊素材組維持原目錄與畫面。

人物所有權另以物理 VGA 像素保存 ID 及圖內座標。已知主角寫入 byte 時，八個位置都更新人物層，底圖層保留；因此新 PNG 的完整輪廓能顯示，原版不透明身形亦會被底圖抹除。其他已知不透明圖像、未知寫入及實底文字使受影響位置的人物層失效，透明文字保留人物並在最後繪字。mode-1 搬移同時複製兩層，模式切換同時清除。缺失／未知背景或完整來源不符時，整次主角呼叫回到原版遮罩處理，不留半張新人物。

已知主角來源拒用時清除該矩形的前一個人物層，避免殘留半張舊動作。原版正常 VGA 每筆有 4×8×25 次實際寫入，與原有 4800／6 的觀測吻合；`ActorCompletions` 只在這 800 次都觀察到後增加，供驗證器等待，並不控制 DOS 或正式動畫時鐘。

新 PNG 必須有透明及不透明像素，取樣端點 alpha 0–3 視為透明，其餘以預乘值插值，輸出為 192×150 的預乘 RGBA。人物畫在已重建底圖上，依 `src + dst×(1-alpha)` 合成，來源圖 bytes 不改動。每個原生像素仍受實際所有權限制，不能跨過其後已畫的 UI 或新圖像。

READY 審查：`actor-background-r1.json` 六次呼叫皆有完整 1600 像素背景，探針最終狀態同 native。`generated-art-r4.json` 內十二張 PNG 都有 alpha 0／255，服色與正面、背面、左右朝向經檢視；步態各自生成，沒有將站姿重複填入。衣褶與局部輪廓是刻意美化，不稱逐像素姿態還原。來源與新素材皆可用固定 SHA 重查。仍未驗的朝向實景及背景維持未知或原版回退，不以它們阻止上述已證實路徑接入。

## 必要驗收

實際原版來源 → 指紋與 PNG → 底圖還原與主角層 → 正常視窗新遊戲、移動、兩次人物頁、返回 → 真正存退讀 → 同輸入客體隔離。另檢查全透明／半透明、原身形消失、已知與未知背景、未知遮罩、同值覆寫、遮擋、頁搬移及模式清除。

十二張生成圖存在不等於動畫接入。未走朝向的實際路段與更廣角色來源須分開記錄；本規格不包含 HD 音樂、其餘地圖圖像或效能完成聲明。所有原版與新衍生圖留本機，不新增 GitHub 圖片授權。
