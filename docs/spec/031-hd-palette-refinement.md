## 已確認的樣式與證據

- 定稿參考：[人物頁原 PNG](../images/hd-palette-approved-r2.png)與[來源紀錄](../images/hd-palette-approved-r2.json)。PNG SHA `a817d0b60b919f79f185efac72440880f7c28a211308db8de3e953f6337ea5d8`，byte 保持。原 B 概念圖 SHA `2a88912c229f226d99ca3f8f6c643137b731eed943585f991ecc631af3b0dad6`。
- 原版來源及字墨生命週期沿 [003](003-noto-runtime-overlay.md)、[005](005-jade-gold-interface.md)。PAM.AY SHA `83e32f132e808d70ac7e170aa1c0019eb4c579b9c785f2cbaf0d3e00af28d6c0`。不增加客體 hook 或推測的新位址。
- 已證實：`Tracker.write` 對真正字模寫入的全部 bit 保存 glyph 來源、局部位置、FG／BG 與原字墨，不只保存有墨點的 bit。因此不透明選取背景可沿字格所有權辨認，不能只按畫面右側或紅色判斷。
- 已證實：正常 F1 收據 `battle-r1/choi-hd-r1/13-F1-character.json` 的七項側欄字串來源偏移依次為十進位 `990,1010,1030,1050,1070,1090,1110`，原生 X=472，Y=`12,39,66,93,120,147,174`。這些是本次 PAM 的 DS 字串偏移，不是 IDA 線性位址。
- R2 的正常路徑與獨立核對見 [研究紀錄](../../RESEARCH-LOG.md#配色方向撤回與原概念圖保守修色-r2)。四點、完整 state／PCM／35 工作檔及 58 個輸入同控制；地圖、玉紙空白區及肖像矩形保持。

## 呈現契約

1. 新增可選 `presentation-palette.json`，schema 1、固定 style `jade-gold-refined-r2`，保留 PAM SHA、B 概念圖 SHA 及上述批准樣張 SHA。只接受這份已批准的設定，無自由腳本或任意色彩規則。缺少時維持舊素材組呈現。
2. 僅在 HD、已驗 PAM／圖像入口、640×200、80-byte pitch、完整可見頁及標準 EGA 色盤下啟用。直接玉紙 46 與 005 的三個 UI 材質須齊備。未知來源、非標準色盤及未完成載入保留既有呈現。
3. Noto／可選字型的 FG 10 改為暖金 `(223,195,121)`，FG 12 改為柔朱紅 `(215,112,89)`；既有 FG 14 暖黃色與其他顏色保持。不替換文字或解讀其玩法意義。
4. 從**當前顯示頁**的字格所有權核對七個側欄來源及原生行位置，禁止沿用前一幀 Scene 字串或只看歷史 Strings。部分遮擋或來源缺失採保守回退。
5. 側欄選取底只接受上述實際字串字格、BG=12、正確行位置及安全矩形 `[472,12+27*r,624,27+27*r)`，將亮紅改為深朱紅 `(128,45,39)`。不改相同位置但屬部隊、圖像、未知字串或透明背景的紅色。
6. 七項側欄確實可見時，才在 005 已驗的下方原生內容區 `[8,192,456,198)` 將色碼 2／10／14 柔化為 `(36,91,56)`／`(110,167,92)`／`(223,190,102)`。長度、位置、更新順序與內容保持，不推測指示的數值語意。
7. 原字墨清除後的底色同樣按 glyph.Before／BG 判定，再套用主機配色。原始 indexed pixels 不變。修色先於 HD 圖像與 Noto 合成，所有既有圖像／部隊／效果遮擋保持。玉紙、框飾、肖像與地表素材 byte 不變。
8. 配色設定在載入時固定，與規則模式分開。關閉 HD 不讀取此設定。字型切換只換 atlas，仍遵守同一組配色與字格所有權；不新增 DOS 按鍵。
9. 新清單損壞、過大、欄位／指紋錯誤或缺少 UI 依賴時，只拒用此配色，保留 Noto 與其他 HD 素材。Engine 提供 `palette_error`／`palette_style`，前端顯示故障提示，不半套套色。

## 實作與驗收

- 實作：獨立主機配色物件、嚴格小型清單載入、Tracker 原生底色與字色映射；不改 dosgolem。舊素材組沒有新清單，現有歷史收據可重生。
- 素材：r25 的 125 檔全部保持，r26 只增加一份設定；由建置工具獨立重建，逐檔雜湊核對。原圖與批准來源另存文件，不重複塞進執行期包。
- 邊界：已知字格、缺一項側欄、錯位置、透明 BG、相同座標的紅色圖像、另一顯示頁、非標準色盤、缺清單與真壞清單。驗證頁面搬移後來源跟隨所有權，不假定 `VisibleScene=map` 即可。
- 正常隔離：新清單／舊素材／真壞清單三組普通冷啟動、自然遭遇、戰鬥數字、F2／F1／返回；比較完整客體 state、PCM、工作檔、輸入、擷取前後純度。四組新畫面與已批准 R2 的獨立原型比較。故障組應同舊色控制。
- 視窗：正常選單選取／取消、F1／F2 往返、戰鬥與返回、字型切換及真正 F7 存退讀。檢查殘色、閃回亮紅、文字對比與原始字墨露出，不以單張無頭 PNG 代替。
- 本規格只驗呈現差異及狀態隔離，不宣稱戰鬥規則、原版 RNG 或全劇情已對拍。海報及工具列另走其規格，不能藉本次修色覆蓋或裁切遊戲區。

READY 審查：原始字格與 BG 的寫入證據、七項側欄真實位置、005 安全區、當前頁與未知來源拒用邊界已足夠；R2 樣式已獲確認。實作若無法按所有權重現批准樣張，退回本規格補證據，不移除來源守衛硬湊畫面。
