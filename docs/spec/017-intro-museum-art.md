# 017：博物館片頭美術

狀態：DRAFT。接續已批准的中國古風手繪方向，先核對正常片頭原圖、構圖與動作，再做可丟棄的並列樣張。未選定的圖像不進正式素材組，不能宣稱 HD 已接入。

## 範圍與證據入口

- 原版來源與固定工具版本沿用 [011](011-intro-title-noto.md)，正常片頭字幕與翻頁入口沿用 [013](013-intro-museum-captions.md)。`TIT3.AY`、`TIT4.AY`、`TIT5.AY` 的完整解碼已逐 byte 同原版緩衝區，不重做 decoder 或標準硬體研究。
- 本次研究輸出集中既有 `workplace/probe-20261023/graphics-first/museum-art-r1/`，用途為博物館原圖目錄、構圖對照、生成原圖／完整提示／來源、原型與驗證收據。原始來源及既有收據維持唯讀，其他音畫原型不搬移。
- 第一條鏈為博物館左側空景 → 兩種配色的真正手繪原型 → 與同狀態原版並列 → 必要的使用者決定。保留現代博物館、入口、畫框、照明及人物行走空間，不把博物館改成古代宮殿，不改劇情、事件、音樂或時序。
- 第二條鏈待原版 evidence 補齊後定義：完整背景／人物幀 → 來源及頁面所有權 → 正常行走、切鏡、畫作近景與轉場 → 字幕合成 → Esc、PAM 與真正存退讀。不能用靜態覆蓋把原版人物或動作遮掉。

## READY 前的必要項目

1. 從完整已解碼資料建立背景／人物／近景目錄，逐項核對實際大小、位置、平面、遮罩、色盤與正常原版畫面；未知語意保留等級。
2. 以真實代表畫面並列原版與 HD，確認配色及構圖差異。Noto／隸書風／草書設定與既有字幕保留，不用生成字體替代。
3. 訂明頁切換、動態人物、重繪、轉場、失效、有限等待及未知來源回退；程式與來源指紋、素材 SHA、權利及正常驗收方法齊全後才進 READY。
4. 實作後以相同輸入、狀態與虛擬時間核對完整客體、工作檔、事件及原版音訊不變。真正視窗連續幀、自然流程、Esc、存退讀與損壞素材各自驗證，不以樣張取代接入。

原版、解碼圖、人物素材、生成圖與衍生畫面留本機，未經另行批准不加入 Git。來源批准與製作紀錄歸 [RESEARCH-LOG.md](../../RESEARCH-LOG.md)，目前狀態歸 [CONTEXT.md](../../CONTEXT.md)。

## MUSEUM-MASK-RESOLVED：六塊資料與背景頁勘誤

已勘誤：TIT4 第六塊。較早 `source-catalog.json` 及研究紀錄只證明記錄邊界與首四塊的非零點，保留其歷史。後續 IDA consumer 與完整正常繪圖已證明本次 VGA 路徑使用第六塊作遮罩，不能再把它列為未知，也不能以色號 0 推導透明。

本節所有程式位址是 **dosgolem／IDA 執行期線性位址**。模組不可變鍵為 DOS／PREDELLA runtime SHA `a764a110b9f8b1d32a6ee9cc0dd650350f917959d647fe4b45cd7f1013eaae68`。正式 `.i64` SHA `dccb45c43ec22165a50422e6dbb46bf0c9f8ce7005c570000b29b8f296614616`；只讀掛載後複製至容器 `/tmp` 查詢，未改名或寫入正式 DB。IDA 9.4／UID 1000 最小探針核對 185 函式及分析輸入 SHA；匯出見 `ida-probe-r1.json`、`ida-museum-r1.json`。

- 已證實：`sub_1BE2` 的 1C63h、1CD4h 等 caller 將 TIT4 偏移、7000h、x byte 與 y 列交給 `sub_52C0`。後者為 52C0h–53F3h，308 bytes SHA `c7c0315ee13ef29e26ea2b35098c3cae6453e4f4e5fcd34da6cee81ae57c4dd3`，返回指令位於 53F3h。原始 `[bp+arg_0]`／`[bp+arg_2]`、`word_D208`、`word_D202` 與 `cs:[bx+4]` 保存在匯出，不用附加語意名取代。
- 設 `n=列寬×列數`，表頭後的塊編號為 0..5。本次 `word_D202=1` 分支依序讀塊 0..3 的四個顏色位元，將塊 5 的 byte 寫至 3CEh index 08h，再讀目的 latch 並寫原色。塊 4 在此分支未讀；它在 `word_D202=2/3` 的替代分支才被使用，該格式與平台未列入本次承諾。
- 遮罩的標準意義採 [FreeVGA Graphics Registers](https://www.scs.stanford.edu/10wi-cs140/pintos/specs/freevga/vga/graphreg.htm#08)：位元 1 選來源，位元 0 保留 latch。正常 134 次 masked return 的所有四平面像素皆同此公式，不深入標準 VGA driver 或硬體時序。
- `word_D208` 的實際目的段為 A000／A400，對應物理平面偏移 0／4000h。列起點按原始 `cs:[bx+4]`、x byte 與目的段算出，不能以當前顯示頁代替。既有選繪圖段、切顯示頁及清頁契約沿用 013，不重開研究。
- 第七筆記錄的 `(32,11)` 是遮罩 1、色號 0 的真正黑墨。正常流程共寫入八次；以「非零色號才有墨」合成會漏掉。`verified-mask-atlas-r1.json` 與十二張 `actor-*-verified-mask.png` 已依 consumer 抽出並檢視，屬原版 RGBA 資料，不是 HD 美術。

## 動態原型的研究邊界

現有 A／B 空景另作可丟棄的即時合成原型，只留 `museum-art-r1/`。它沿用正常 DOS 執行、r15 字型／配樂與原版人物，在已核對的左側背景及兩物理頁上比較配色；右側背景、近景及其餘動態美術保留原版，不能當成完整 HD。原圖不改寫，只從相同中央畫幅建立顯示輸入。

原型不另訂閱或覆蓋核心單一視訊 callback，也不更動正式 Engine、前端或素材組。先用原版背景重建模式比對完成交易的呈現像素，再比較 A／B／控制的完整客體、輸入與音訊。交易中的完整幀保留、黑墨、右緣跨列寫入、字幕及 Esc／PAM 退休必須可核對。尚未補足未知寫入失效、素材群組故障、完整 HD 動態資產與正式驗收前，不把原型移入 production。

## MUSEUM-PAGE-COPY-RESOLVED：原型清頁誤分類勘誤

前節 r1 的「六次清頁」及 serial 46 目的頁解釋沿用當時分類，保留為失敗歷史。已證實其中五次為**方向固定的頁面複製**，只有一次是真正清頁。r1 將兩種操作一起清除兩頁主機模型，既丟掉來源頁，也沒有將人物與背景複製到目的頁。`word_D208` 只供這次真正清頁選頁，不能用作複製目的頁。

本節程式位址均為 DOS／PREDELLA **執行期線性位址**，不可變模組鍵及正式 DB SHA 同前文。沿用 IDA 9.4／UID 1000 的 `py312-v1` 映像，在 `/tmp` DB 副本查詢，未修改正式 DB、名稱或 bytes。`ida-clear-r2.json` 保存五個原始函式、呼叫者、位元組及指令，SHA `809f7f5e23252cabc55d022596e44c90b9fbbed7cb879d93c9f197daf2136a5f`。既有 `captions-r1/ida-pages-r1.json` 的分派指令與本次相同。

`trace-pages-r2.go`／`page-trace-r2` 以普通 VGA／AdLib 冷啟動到 21400 ms，無快照續跑、RAM 注入或另裝視訊 callback。每次交易前後都讀兩頁各 16384 個 byte 位址的八個色號，共 262144 個索引。`audit-pages-r2.py`／`page-audit-r2.json` 獨立套用上述來源、目的與長度，六次返回的完整兩頁皆逐 byte 相同，包含來源頁、目的頁尾 384 byte 位址與其他未受影響區域。順序為 5D76 一次、5D9C 兩次、5B0C 一次、5D9C 兩次；不依實際變色點推導完整作用範圍。

無探針 `page-control-r2` 與觀察組完整 state 同 SHA `b1cafef3791e821685c691806d4096caa5ee53bc855418ff4ab28df1feeaf6b7`，9 工作檔、原版檔案事件與整段 FM PCM 相同；PCM SHA `4dc570e5d9677e70b846b6d2844c3490cd800503a807a9bad60e09ee8cb98212`。本節只補足頁面交易，不重新研究標準 VGA driver。

據此製作獨立研究副本 `museum-presenter-r2.go`：只清除真正清頁的目的頁；兩個複製分派在返回時深複製來源頁的背景識別與人物墨跡至固定目的頁。來源未知時只讓該目的頁回原版，保留其他頁。原型保留前後交易與現行 Noto 字幕，來源／分派／consumer 皆核對固定程式 SHA。r1 原碼、程式、收據與失敗圖不改寫；正式 Engine、前端及 r15 不變。這項修正仍屬 017 DRAFT 原型，不代表整體 HD 或正式合成已完成。
