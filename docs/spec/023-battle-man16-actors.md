## 候選契約

1. 可選 `battle-actors.json` schema 1，限定 `MAN16.EGG`、來源 SHA、`B-bright-painted-r1` 與既有批准圖 SHA。四筆按原記錄排序，來源索引 86 至 89、主機 ID 87 至 90，不占用戰場背景 ID 86。逐筆固定檔名 `battle-man16-<記錄>-r1.png`，保存 PNG SHA、尺寸、來源矩形與目的矩形。缺清單保持原版。
2. 先核對原始 EGG、四張圖的雜湊、PNG 尺寸上限、真透明與不透明主體、矩形及識別碰撞。全組成功才更新 ByNative／Actors／ActorSHA／BattleActors；任一錯誤整組拒用並回報 `battle_actor_error`，既有 Noto、其他人物、背景及音樂保持。需要已載入的 GRO02 背景，缺依賴回原版。
3. 原始來源矩形包含所有 alpha 大於 3 的像素；外側只可有可忽略的透明殘值。取樣快取採既有預乘 RGBA 雙線性及 alpha≤3 歸零，填入 264×300 透明畫幅。目的矩形以原版位置及黑腳觀察校準，屬刻意美化：0 為 `[30,84,231,192]`、1 為 `[30,96,231,180]`、2 為 `[27,36,234,174]`、3 為 `[33,60,228,174]`。順序皆為 x、y、寬、高，單位是 HD 顯示像素。第 0／1 筆的原版橢圓投影不重畫；第 2／3 筆下方留白，避免落地位置漂移。
4. 只有六塊完整 hash、88×50、背景頁來源與目前 GRO02 全矩形已知時才啟用。只授權 `0626` 的背景式人物路徑，`04F2` 不把本組當成主角或軍隊頁人物。先沿 021 複製 A400 所有權，再將整幅的 actor 所有權設為相應記錄；透明處呈現已驗背景，不能露原版人物與投影。未知圖像、其他頁／模式、背景缺失或還原均依既有失效與回退。
5. 沿用 022 的交易守衛與返回點快取，不新增客體寫入、等待、按鍵、亂數或時鐘改動。原文、Noto 字墨、其他單位與標記的遮擋繼續由原版寫入及所有權追蹤處理；被實際覆寫的區域須清除新人物，不能強制永遠置頂。
6. 來源 → 固定記錄 → typed 清單 → 主機取樣 → 正常遭遇及四姿勢 → 返回地圖／F1／F2 → 真正存退讀，需分開驗。狀態／音訊／工作檔同輸入對照；故障需破壞最後一張真 PNG，驗整組回原版。純 unit 與快照恢復不取代正常路徑。

## READY 審查結果

`man16-art-r1/registration-r1.json`、`geometry-source-r1.json` 與 `registered-comparison-r1.png` 已核對及看圖。四張取樣都保留完整可見身體與尾巴，背景透明；四個 alpha>3 的快取界限分別為 `[30,84,259,276]`、`[30,96,261,276]`、`[27,36,261,210]`、`[33,60,260,234]`，此處為左、上、右、下的開區間。來源矩形外只有 alpha≤3 殘值，PNG byte 保留。前兩筆腳部校準在 y276，後兩筆保持 y210／234 的離地高度；四者在同一 264×300 畫幅展示，沒有用整張縮放把躍起拉回地面。
