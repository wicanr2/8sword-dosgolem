## 幾何與刻意美化

座標為原生 640×200，矩形右／下界不包含。顯示仍用 x3／y6，來源順序、遮擋與頁搬移保持 004 契約。框飾是程式繪製的幾何介面，使用已匯入的玉紙材質及金色線條，不生成或搬用原版像素美術。

- 外框左柱 `(0,2)-(8,199)`、分隔柱 `(456,2)-(465,199)`、右柱 `(632,2)-(640,199)`。左上框 `(8,2)-(456,12)`、左下框 `(8,187)-(456,192)`；地圖安全矩形仍為 `(8,12)-(456,187)`。
- 右側橫框 x 為 465–632，起始 y 為 2、29、56、83、110、137、164、191，各高 7 列。指令文字安全區仍在框飾之間，不把金線伸入字格。
- 底部儀表的外緣在 `(8,191)-(456,198)`，內部保留黑色。原版後續填色照常顯示，不將它猜成其他玩法數值。
- 主選單底圖以深玉紙、細金邊與幾何回紋繪製；三次原版呼叫仍各自控制其位置。訊息框內部保留原版色碼 8 的 `(85,85,85)` 平色，外緣改金玉框；這使不透明字背景及原版反白還原不產生不同色塊。
- 訊息框的原生平色矩形恰為 `(6,3)-(442,72)`，436×69=30084 個像素，外緣換算後各厚 18 px。其文字安全範圍不縮小。
- 外框的內容區維持黑色；人物頁底紋與地圖仍由後續原版圖像呼叫覆蓋。金玉框飾是美化，不宣稱與原版逐像素一致。文字與紅色選取仍由 003 追蹤原版繪製。

## 資料與失效契約

- 新增固定三筆非 PMAP 來源，原版 PMAP 解析仍恰為 68 筆。加上主角肖像後，呈現來源目錄共 72 筆；每個 ID 都保留已驗尺寸與完整來源指紋。
- `terrain.json` 可加入 `ui: {"style":"jade-gold-v1","paper_source":46}`。必須先驗證並載入直接玉紙素材 46，才能建立三筆介面快取；缺材質、未知樣式、錯誤依賴或重複來源使整組圖像拒用，Noto 仍可獨立運作。未指定 ui 的舊組維持原樣。
- 全幅外框有 128000 個像素，`graphicCell.Local` 改為 uint32，ID 仍 uint16；這是主機記憶體的座標，不改 DOS 記憶體、存檔或快照格式。逐像素所有權約由 2 MiB 增至 4 MiB，三張介面快取合計約 12 MiB。
- 仍以真實寫入、同值失效、mode-1 搬移及模式切換更新所有權。背景移入移出、F1、返回、F7、儲存與讀檔不能留下上一畫面的框或字。內容區的未知寫入保持原版，不因「在選單附近」便套用素材。

## 審查與驗收

READY 前核對輸入 SHA、原版三筆記錄及幾何、位址基準、128000 的座標範圍，以及平色背景與原版不透明字的相容方式。

審查結果：`graphics-first/ui-geometry-r1.json` 逐像素核對地圖、七個指令內容區與儀表內部全為黑色；MSGBOX 的 30084 個色碼 8 恰好填滿上述內容矩形。初次把訊息框視為各邊 2 px 邊框的假設被來源否定，改依真實 6×3 原生像素的邊框幾何，不以放寬斷言過關。已核對三筆完整來源 SHA，外框最後像素序號為 127999，須使用 uint32。

- 真實來源與來源指紋核對，包含外框最後一列超過 65535 的圖內序號、同位址與跨頁搬移、局部同值覆寫失效。
- 舊素材組的保存圖片保持不變；新組必須真正顯示金玉框，不能以資產拒用後回退作成功。
- 正常視窗操作主選單、新遊戲、人物頁、返回、系統選單、真正存退讀。檢查字形安全範圍、選取還原、連續幀與舊畫面殘留。
- 同一冷啟動及等價輸入下，完整客體狀態、原生畫面、輸入、載入事件與 DOS 工作檔保持相同；主機合成輸出則有預期差異。
- 缺失或損壞真實玉紙素材時整組拒用，Noto 保留。新增來源與使用過程均須留下可追溯收據。

本規格不授權把其餘素材、角色動畫、HD 音樂、效能或全遊戲驗收視為完成；這些仍屬持續目標。

## 限定驗收結果

- 真實 BUMBOO／MSGBOX 來源、內容安全矩形及平色底通過。全幅最後序號 127999 的實際寫入與跨頁複製通過，底部非黑金玉框的取樣沒有 uint16 回繞。未知介面樣式、缺失或錯誤玉紙依賴均拒用。
- `jade-ui-r1` 同輸入冷啟動至 250000000 步，35 筆素材確實載入，381 次 HD 來源呼叫、1051365 個合成原生像素。完整客體狀態、31 個工作檔、輸入與載入事件同 native；狀態 SHA 仍為 `4b55d17998e2fa05176fdf9c2a4deab2321c15d6fd79164d88bfde82d82c64ac`。`jade-ui-isolation-r1.json` 要求實際圖像合成，不接受回退充數。
- `jade-ui-old-pack-r1` 的舊 32 筆素材組，十張保存 PNG 與 `painted-portrait-r1` 完全相同，客體狀態相同。
- `jade-ui-visible-r1` 以兩個冷啟動視窗程序完成主選單、新遊戲、兩次 F1、返回、F7 開關、移動、儲存及回 DOS，再重開繼續與 F1。158 幀／20 次改變、97 幀／9 次改變已獨立解碼及目視檢查；框飾沒有進入文字與地圖安全區，返回及選取還原無舊框或文字殘留。
- 原版真正儲存／讀回的 2987 bytes 與 RAM 相同，SHA `29dd62aed5918ac7ef9dcd4020a90d8a8ff84355bcd9405ded3432116b1a2359`。兩張地圖的差異限主角動畫區，不宣稱整幀相符。快照只在結束後作 0 指令的只讀核對。
- `jade-ui-invalid-r1` 與 `jade-ui-paper-bad-r1` 分別注入未知樣式、破壞真實玉紙 PNG。兩者整組圖像拒用而 Noto 保留，十張保存 PNG 同純 Noto 基準，客體狀態及 31 個工作檔相同。這是實際無頭故障流程，不冒充新增活視窗故障提示驗證。

詳細收據皆位於 `workplace/player/`，輸入／輸出建置 SHA 與逐幀檔保留於各路段。範圍不包含未走的畫面、戰鬥、角色 HD 動畫或全遊戲驗收。
