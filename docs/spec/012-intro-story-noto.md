# 012：開場故事直排文字

狀態：限定 CONFORMED。先經 DRAFT、正常來源審查及 READY，再實作與驗證。範圍限 PREDELLA 正常開場的五頁故事文字。沿用已批准的 Noto Sans CJK TC Black 900，保留原文、直排、分頁、逐字順序與 Esc。本項早期收據使用原版背景；現行深藍五頁與彩色前導的追加呈現、第一頁交接及限定驗收見 [014](014-intro-story-background.md#彩色前導正式追加驗收)，不以本項文字驗收外推其他美術。

## 原版證據

原版 EXE、PAM、dosgolem 與三份補丁同 011。IDA 9.4 讀取既有 `PREDELLA-runtime.i64` 的一次性副本；不修改資料庫或名稱。以下均為執行期線性位址，IDA 基底直接對應，不是壓縮 EXE 偏移。

上述三份字表／字模的正常執行期擷取逐 byte 同解包輸入。TIT6X 的五次實際 `sub_576A` 參數均為 `[0,6000h,0,0]`；完整緩衝區逐 byte 同獨立 parser。TIT6X 是藍色線稿背景，文字另由原文表繪製，不能把背景圖當作故事文字來源。此證據補足 011 當時尚無 TIT6X 完整緩衝區的限制。

- `sub_203E` 至 `0x21AB`：故事控制，74 筆記錄，每筆 24 bytes 加兩個零。每次複製一對 bytes 至 DS:0866，以 `sub_58B1` 顯示；記錄最後一筆為零，仍保留原版呼叫。
- 正常流程共 888 次 `sub_58B1`。第 i 次從零起算，欄 c=i/12、列 r=i%12。來源為表內 `26*c+2*r`；參數 `[0866h,75-5*(c%16),4+16*r]`。x 單位是八個像素，y 為原生列。五頁含末頁十欄，第一頁十六欄的原生截圖已核對。
- `sub_5910` 以兩個 Big5 bytes 搜尋上述字碼表，回傳字模偏移 `30*ordinal` 或 FFFFh。`sub_4C74` 讀 CS:(偏移+6) 的十五列、每列兩個 bytes。非 CJK 經 `sub_5954`，本故事為兩個空格或零，不猜補缺字。
- 原版每字呼叫 `sub_21AC(100)`，頁尾呼叫 6000；這是原版參數，不據此宣稱實際毫秒時長或深入計時 driver。呈現跟隨實際呼叫，不另設播放器計時。
- 原文含「地嶽變」、「祇」及全形直線等字，保留原版 bytes，不依手冊或現代用語改寫。

固定程式窗：203E/366 bytes SHA `bba7997a5a28f67a58f0193c1ff2adde6c498b8af8f1cd290a786aad603de553`；58B1/95=`c05428726639bb22cfaa28ed4078610189fbddb2fe093d4d2ba7830b8709aa10`；4C74/352=`1aff4e0dbdf1831e8ba94e960bc6a0730a2edb075ac4c961a31d4a9b169beb6b`；5910/68=`eaee2bb6409de05595174b268acd57cd0e3afe14365db06ad56da5eca14952c9`。576A、5B0C 同 011。

## 呈現契約

1. 新增獨立故事字集。353 個 CJK 加 95 ASCII，使用相同 Noto 來源、TC index 3、900 字重、48 px、64×64 字框。保留既有素材組所有 bytes。原文、字碼、字模、atlas 與來源記錄只留本機。清單保存原版、執行期、字碼、字模、字型及 atlas 雜湊；未知、重複、缺字或越界拒用。
2. 只在固定程式窗、DS、完整原文／字碼／字模、顯示幾何及 TIT6X 解碼皆符合時啟用。正常入口是 `sub_203E`。逐次核對 888 個文字呼叫的來源 bytes、返回位置、欄列與順序；不依檔名或過去曾命中而顯示文字。
3. 每個已出現字的原生 16×15 矩形先還原 TIT6X 背景，再於放大後的安全矩形內置中畫 Noto。保留原金黃色方向，不以裁切掩蓋缺字。空格與零不畫字。其餘畫面、原版字碼、繪圖及遊戲狀態照常執行。
4. 原版字模交易內呈現完整 Noto，避免分平面字墨露出。頁面背景重畫時，最多保留上一張完整 HD 幀至 `sub_576A` 的 583D 返回；1322 退出入口保留最後完整幀至原版模式改變或 PAM 退休。單次交易上限 2000000 客體 cycles；逾時恢復原版並記錄。這是故障上限，不是原版時長。
5. Engine 將同一視訊事件轉送既有 Tracker、標題及故事，不能覆蓋單一核心 callback。未知寫入、來源／順序不符、模式或幾何改變停用；PAM 後永久退休。故事資產故障僅回退故事文字，保留標題、PAM Noto、圖像及音樂。
6. 合成前複製共享底圖。Frame 不寫客體，沒有輸入、時鐘、亂數、音樂或 DOS 狀態變更。狀態分開記來源、文字數、頁數、真正合成、逾時與錯誤；真正 Draw 才記可見。

## 驗收

- 888 次來源／位置／順序，353 個字碼／原字模及 TIT6X 的獨立核對。原始來源與基底素材不變，獨立重建新字集相同。
- 正常冷啟動的五頁、逐字變化、頁面清除、自然進入 PAM；另在故事普通 Esc。實際視窗與連續幀核對殘字、首露原字及頁面失效，接續新遊戲、F1、返回與真正 F7 存退讀。
- 同輸入、時間的原字／Noto 完整客體、DOS 工作檔、事件及音訊相同；Frame 前後完整客體不變。比較只排除明列的呈現差異。
- 真實損壞故事 atlas 後回原字，其他 HD 保留；失去返回必須有界回退。單元測試不代替正常視窗。

證據足夠支援本功能後停止字庫及標準計時研究。故事背景、發行商字樣、其餘文字及圖像不由本規格宣稱完成。
