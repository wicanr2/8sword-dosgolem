# 004：原版圖像觀測與中國古風 HD 素材

狀態：READY。已核對 IDA 原始指令、731 次正常執行期呼叫、來源完整指紋、遮罩位置及只讀狀態隔離，授權以下實作；尚未通過實作驗收。承接 [003](003-noto-runtime-overlay.md) 的只讀呈現層及使用者批准的 B 明亮手繪風格。這是完整 HD 圖像接入的第一批，接草地、水面與岸線；山地、建築、角色、介面及其他圖像仍須續做，不能以這批宣稱整體 HD 完成。

## 來源與證據

- 原版 `PAM.AY` SHA-256 為 `83e32f132e808d70ac7e170aa1c0019eb4c579b9c785f2cbaf0d3e00af28d6c0`；`PMAP.AY` 65317 bytes，SHA 為 `9db04157a546a4fe8615becf483520b1a7d3a0a5357fef56f88dcb694dd21e02`。
- 工具為 IDA Pro 9.4、Go 1.24.13、dosgolem `f79eab6d` 加本案兩份觀測／顯示頁補丁。證據在 `workplace/probe-20261023/graphics-first/` 的 `ida-graphics.json`、`graphics-runtime.json`、`graphics-runtime-proof.json`、`pixel-check.json`，均只留本機。
- PMAP 有 68 筆兩個 little-endian word 尺寸的圖像。前 65 筆為寬 8 bytes、高 25 列，後三筆為寬 1 byte、高 3 列；每筆長 `4 + widthBytes × height × 5`。首四組是原生色碼 bit 0–3 的平面，byte 內 MSB 在左。正常地圖 `(8,12)` 起的 7×7 格有 48 格與來源圖塊逐 RGB 像素相同，另一格含主角。
- PMAP 的第五組由另外兩條顯示分支讀取，不是 EGA 透明遮罩。六組圖像的第六組才在 EGA 路徑逐 byte 寫入 GC register 8。這由下表原始指令與實際來源指標佐證，不由檔案整除猜測。

## 位址與呼叫契約

保留原始名稱及 bytes。IDA 位址為 MZ loader linear，執行期 CS:IP 以 overlay 載入段／重定位段 `0110` 為基準。下列是此來源已證實的正常 VGA 路徑；其他顯示模式不擴張為已驗。

| 用途 | IDA 原始定位 | 執行期入口／寫入指令 | 資料 |
|---|---|---|---|
| 有遮罩圖像 | `sub_24112`，IDA `0x24112` | `14D2:04F2`／`14D2:057D` | 四色平面、另一顯示分支資料、第六組 bit mask |
| 五組不透明圖像 | `sub_2438F`，IDA `0x2438F` | `14D2:076F`／`14D2:07CF` | EGA 只讀首四色平面，包含 PMAP |
| 四組不透明圖像 | `sub_245BC`，IDA `0x245BC` | `14D2:099C`／`14D2:09FC` | 首四色平面，包含實際 UI 背景 |
| 顯示清除 | `sub_2495E`，IDA `0x2495E` | `14D2:0D6D` | 原版清除全部執行，主機所有權失效 |

far cdecl 參數依序為來源 offset、來源 segment、目的 byte 欄、目的 y。來源起點兩個 word 為寬 byte 數及列數。目的 segment 讀 DS:748A，列位址表是 `14D2:0006 + y×2`，與 003 字型使用同一張表。VGA 路徑實際列距 80 bytes，目的在 A000／A400；寫入前 DS:SI 與 ES:DI 仍指當前 byte。

正常冷啟動同輸入到 250000000 步，捕捉 731 次圖像呼叫：6 次有遮罩、718 次五組不透明、7 次四組不透明。716 次完整來源對上 PMAP；所有記錄的目的幾何均在 640×200 範圍。觀測後完整客體狀態仍同 native，SHA 為 `4b55d17998e2fa05176fdf9c2a4deab2321c15d6fd79164d88bfde82d82c64ac`。

## 呈現與失效

1. 新增的圖像掛勾只讀參數、來源與顯示狀態，不跳過原版繪圖，不改客體暫存器、記憶體、事件、亂數、存檔或時間。
2. 在圖像入口核對來源尺寸、範圍及首四色平面的完整指紋。未知圖像保留原版；已知圖像只在真正寫入的像素建立主機圖像所有權，保留來源圖像 ID 及圖內座標。讀表頭前即要求來源全部位於實體線性位址小於 `0xA0000` 的傳統 RAM，且 offset 加資料長度不能越過 64 KiB。這避免 `Oracle.Bytes` 的機器讀取碰到 VGA latch；所有已驗來源都在此範圍。目的各列須符合已驗的 80-byte 列距；不吻合時回退，不猜補裁切或位址。
3. 五組／四組圖像覆蓋所有八個 bit。有遮罩圖像依第六組 mask 的 bit 處理：1 才覆蓋，0 保留既有背景所有權。同值覆寫也算覆蓋。未知 sprite 的不透明部分保留原版前景，透明部分保留 HD 背景，不能把整個 byte 清成洞。
4. 003 已證實的 mode-1 搬移同步複製圖像所有權與局部座標，包括相同來源／目的 byte。其他寫入使目的所有權失效；模式切換清除全圖。圖像所有權變動參與同一個呈現快取世代。
5. 原生字墨先依 003 還原，HD 圖像在 Noto 文字之前合成。透明字保留底圖所有權，實底字使底圖失效。不能讓材質蓋掉字或留下原生字墨。
6. 僅在已驗的 640×200、標準 EGA 色盤及合法顯示列距合成；色盤、模式、來源或圖像幾何不吻合即保留原版。使用目前 CRTC 起點，不把 A000／A400 當成固定顯示頁。
7. 開發畫布沿用 1920×1200，原生 x3／y6。草地與水面每原生圖像為 64×25，對應 192×150。HD 取樣使用來源圖像內座標，因此背景搬移後圖像細節跟著原圖，不能固定貼在螢幕上。

## 資產契約

- 由本機資產目錄的 `terrain.json` 原子載入一組素材。清單包含 schema、PMAP 來源 SHA、批准樣式識別、每筆來源索引、生成圖檔名／SHA、實際尺寸、提示檔及權利分類。實際讀取 PNG 尺寸，不相信生成請求的尺寸。
- 第一組是已生成的草地及水面，來源 PMAP 0／1；其他索引尚未取得素材時原版回退。兩張圖皆是新繪素材，不以原圖放大或插值當成 HD。
- 匯入保留生成圖原始 bytes；正式呈現以雙線性取樣成目標圖塊，邊緣 16 px 可作對邊漸混以連續重複，這是已批准畫風內的材質取樣，不改原版位置與遮罩。缺圖、破損、雜湊或來源不符時整組退回原版圖像，Noto 文字仍可獨立運作並回報原因。
- 4×4 生成圖集因岸線錯位已拒用。不得拿生成圖的海岸形狀反推原版地形或遮罩。
- 生成原圖、原版圖集及匯入素材均留本機，未取得額外散布授權，不因程式可推送而上傳圖像。

### 材質取樣與岸線美化

首批實際重播已顯示兩張生成圖，但整張縮成 192×150 後細節太碎，岸線仍為原版，無法視為完整場景。這項修正屬已批准 B 風格內的呈現實作，不改地圖資料或通行規則。

- 清單可為材質指定 `source_rect: [x,y,width,height]`，以原始 PNG 的這個矩形取樣。必須完全在已驗證的圖內，寬高皆為正；未指定時仍取全圖。新一組取中心 256×200，保留原始 PNG bytes、SHA 與尺寸。`sampling` 為 `periodic` 時才做對邊漸混；`bitmap` 不漸混，供後續完整圖像使用。未知模式使整組回退。
- 原版 PMAP 2–13 的四色平面只出現色碼 0、1、2、8、9、10、11、14。已證實的是這項像素資料及 2–13 的岸線畫面；以下色群轉換是刻意的視覺近似，不能當作原版地形或透明遮罩。
- `composites` 清單允許來源 2–13，各以已載入的草地 0 及水面 1 合成。由原版色碼 2／10／14 計入草地，1／9／11 計入水面，0／8 不投票。以水平權重 1、2、3、4、3、2、1，垂直權重 1、2、1 的 7×3 視窗求草地比率，邊界取最近的原版像素。無票時保留 0.5，將比率 0.4–0.6 線性映射至 alpha 0–1，其外截至端點。再以原版 x3／y6 雙線性取樣 alpha，混合兩張 HD 材質。此濾波只移除原圖的紋理雜點並柔化邊界，不聲稱逐像素復原原作者的隱藏遮罩。
- 合成項不能重複索引、引用未載入材質或鏈式引用其他合成項。岸線含未知色碼時整組拒用，避免誤套到其他圖像。原版圖像所有權、角色第六組遮罩、頁搬移與 Noto 順序仍遵循前節。
- 驗收核對 14 筆圖像實際啟用、岸線與主角透明部分、正常人物頁往返、狀態隔離及故障回退。這個視覺近似不解除其他圖像與 HD 音樂的未完成狀態。

## 審查與驗收

升 READY 前核對上列 IDA 與執行期來源、遮罩位置、參數、幾何、原始來源 SHA 及只讀狀態隔離。

審查結果：原版三個入口及寫入指令的對應、far 參數、A000／A400 目的段與 source DS:SI 均已由執行期確認；731 筆幾何無越界。731 次中 716 次與 PMAP 的完整五組記錄匹配，其餘為真實角色、UI 及人物圖像；未知來源保留原版。遮罩偏移 `4 + 5×area` 由 `sub_24112` 的 `var_A` 資料流證實，與已存在 VGA 寫入模式 0 的 bit mask 契約一致。完整原版狀態與基準相同，因此未再展開遊戲無關 driver。

- 真實來源解析與拒絕損壞／越界，遮罩透明 bit 保留背景、同值不透明覆寫失效、重疊／同位址搬移均須驗證。
- 正常冷啟動、新遊戲、移動、F1、返回、F7 及真正存退讀需在視窗抽樣；連續幀驗證圖像不殘留、文字不被蓋住、圖像細節跟著來源搬移。
- 等價初始狀態與輸入下，關閉／開啟 HD 圖像的客體狀態、原生畫面與 DOS 檔案必須相同。合成輸出應確實不同；不能以資產拒用後的原版回退算成功。
- 故障回退以移除或破壞真實圖像測試，原始來源不可修改。記錄合成及模擬效能，不以圖檔存在當作驗收。
- 完成這一批只代表兩張生成材質、十二種岸線合成及其圖像生命週期。完整 HD 圖像、其餘資產與 HD 音樂仍維持原目標，分項記錄未完成，不縮小使用者目標。
