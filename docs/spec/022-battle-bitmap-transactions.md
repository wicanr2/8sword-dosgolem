## 正式契約

1. 僅在固定 PAM、640×200、VGA mode 值 1、A400→A000、11 bytes×50 列，且 A400 的完整來源矩形仍屬已驗 GRO02 背景 ID 86 時啟用。未知素材、幾何或來源頁保持 021 的原版回退。既有地圖主角、F2 民兵及其他場景不因新掛勾加入等待。
2. 在已核對入口開始一筆主機呈現交易，記錄原始入口、開始步數、矩形、預期寫入點與次數。只讀觀測實際寫入，依已核對 RETF 結束，不能用場景、時間或猜測下一張圖替代返回。完成時必須有預期次數；未知寫入、模式改動、新交易覆蓋、錯誤返回或次數不符均作廢交易並回原版可辨識呈現。
3. 交易進行時 `Tracker.Compose` 保留前一張完整快取，不更改可見來源、場景或快取世代。沒有既有完整幀時不畫空白。曾保留畫面後，在第一個真正返回點以既有 Compose 更新完整快取，再交給正常視窗；避免連續交易使每個呈現時點都落在另一筆交易內而長期沿用同一張圖。每次保留至多觸發一次返回點擷取，不為每次繪圖建立新畫面。這只影響呈現；不補跑 DOS、不睡眠、不攔輸入、不延遲音訊。
4. 正常完成依返回，安全上限為自入口起 100000 個客體步數，超過時取消保留並回原版。上限超過 r10 最大觀察值三倍，用於缺返回的失效防護，不用來判定正常完成。統計開始、完成、保留幀、失效與最大步數，故障不得無界維持舊畫面。
5. 不跳過原版中間寫入，不改 VGA、原版時序、活動標記、素材格式或輸入。021 的獨立背景清單、故障範圍與 r17 的 81 檔不變。部隊 HD 仍未由本項完成。

## 必要驗收

- 正常無頭的控制／啟用交易及真實壞背景三組，同輸入／時鐘的完整客體、原版索引、輸入、事件、工作檔與 PCM 相同，Frame 前後客體純度保持。只對已實際觀察的正常路段聲明。
- 完成呼叫仍同獨立原版公式。交易內的每次 Frame 與前一張完整幀相同，返回後可立即恢復新畫面；不靠挑幀、固定等待或原生索引相同宣稱 HD 呈現通過。
- 實際 XTEST 觀測與正式視窗分開保留建置來源、程式 SHA 及逐幀收據。正常 V／Ctrl、撤退、結果、F1／F2 與真正 F7 存退讀，連續 Draw 解碼並看圖。至少一個完整戰場 Draw 的背景、原版前景與 Noto 分層同獨立重建。
- 失效護欄包括未知寫入、模式切換、同模式重設、缺返回與安全上限；只改主機 metadata 的診斷與原版真的發生事件分開記錄。缺資料時明示跳過測試，不能把原版回退當作交易有啟用。

證據足夠後停止繪圖 helper RE，回呈現與部隊美術。標準 VGA 時序、戰鬥規則、其他場景及整個 executable 不在本項研究範圍。
