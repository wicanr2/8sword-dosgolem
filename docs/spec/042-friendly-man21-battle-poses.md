## 存讀探針的伴隨地圖勘誤

`ally21-source-r1` 與控制組固定執行前時鐘 12:00:00.00、3000 cycles/ms，原版 RND seed 未解。142 個普通命令正常探索到 F5 的 3,25，沒有遇敵或任何 0626 部隊呼叫。F1／F2 與 F7 存退完成。該輪初始探針只複製 `gamedata.ay`，不能稱完整延續前輪探索紀錄，也不以無遭遇推論原版遭遇公式或戰場來源。

冷啟動負對照 `ally21-reload-r1` 證實：只帶人物存檔時，RAM 讀回 2987 bytes、F2 兵力及 F5 座標都保持，但 F5 探索區域有 21168 個像素不同。原行程 F7 同時保存了 `map01.ay`，SHA `7074c69d69a8bce2ab697f10aed02d8a521bf94509bcc1c6d05c90d2cf7290eb`。不能把這項差異當成動畫相位，也不能以人物存檔相同宣稱地圖完整存讀。

研究程式 `ally21-source-build-r2/src/tools/probe-ally21.go` 增加可選 `-game-map`，在 Engine 開啟前將該真正 MAP01 伴隨檔複製到可寫存檔層。限定長度 5761 bytes，同時要求人物存檔，另存來源 SHA 收據。只修正研究輸入，不改客體 RAM、原版存檔 bytes、正式 Engine 或前端。正式前端原本沿同一個持久化存檔目錄讀寫；這項勘誤不宣稱發現正式前端遺失地圖。

核對工具：[audit-friendly-man21.py](../../tools/audit-friendly-man21.py)。在 Pillow Docker 傳入 `--source` 原始 MAN21、`--build` 首輪探針建置、`--reload-build` 修正建置、`--observed`、`--control`、`--reload` 完整兩檔冷讀、`--partial-reload` 單檔負對照、`--prototype`、`--rebuild` 及不存在的 `--out` JSON。來源未出現時輸出 `incomplete-source-coverage`，不把快取重建或存讀通過當作 READY。四個目標來源的六塊及返回色碼仍須補齊，才可進入正式接入審查。

## 限定研究結果

`ally21-source-isolation-r1.json` 通過觀測隔離及兩檔存讀檢查，來源覆蓋明確為 `incomplete-source-coverage`，四筆皆未取得。不將本節當作實作授權。

- 原型與獨立重建六檔逐 byte 相同。兩組正常行程各 1892 幀，完整 state SHA `f284aceccffa10d6b327fc0fe99c744dd6c74437e053446a4bdc9935b05a8ee6`、PCM SHA `aa9ee95747ff520493cf048879a0a431e1a3ec9b523df1e284018bb1a692af0a`、無損串流、普通命令、全部 checkpoint PNG、22 工作檔及輸入／文字／I/O／EXEC 事件相同。沒有以固定時鐘冒稱固定 RND seed，也沒有取得可驗證的戰場返回色碼。
- `ally21-reload-r2` 冷啟動普通繼續，帶入 F7 的 `gamedata.ay` 與 `map01.ay`，314 幀；同前兩組共 4098 次 Frame 純度。正常讀回 RAM 的 2987 bytes 同 `f1998cd5…c2ea`，地圖檔同 `7074c69d…90eb`，DOS 退出 0。F2 逐 byte 相同。F5 在真正錄製的第 205 幀、step 30198653，全幅 2304000 像素同存前畫面，沒有遮罩掉地圖差異。
- 固定 checkpoint 的 F5 另有 108 點黑白差異，限 `(336,378)-(348,390)` 的原版位置閃爍標記。兩次最終擷取沒有對齊閃爍相位，故不稱固定 checkpoint 全幀相同。上述實際串流內的全幅一致幀，才是相位對齊的畫面證據；也不延伸成客體同狀態 parity。
- 單檔負對照保留於 `ally21-reload-r1`。它的 21168 點探索區域差異與修正後的 108 點閃爍差異分開記錄。核對器初次以單檔冷讀失敗、修正後因固定相位假設再失敗；這兩項分別是研究輸入及驗證假設問題，不記成正式 Engine 缺陷。
- 修正探針各保留 44 筆建置輸入、Go 1.24.13、完整來源及程式雜湊。首輪程式 SHA `c0ad1381…9422`，修正程式 SHA `4596bacd…4af6`。正式 41 個套件來源保持；研究新增項只有唯讀觀察、普通輸入、輸出與伴隨檔匯入。
- `ally21-source-r2` 以招募當輪的完整兩檔正常繼續，沿相同前九次向西操作，F5 為 36,37，404 幀、退出 0，仍沒有戰場來源。這是輸入修正後的一次窄抽樣，不重走首輪 142 命令，也不把有地圖伴隨檔與遭遇出現之間當成已證實因果。

下一步先查目前正常玩家路徑的遭遇前置，再取得友軍動作；不反覆重跑上述無遭遇路線、不換時鐘或編成來湊姿勢。完整續玩輸入須保留客體實際保存的伴隨檔。此處只驗 MAP01，其他大陸的檔名與持久化範圍仍依真正 I/O 核對。這輪沒有正式素材、前端或核心改動，r40 與 041 已驗範圍保持，亦沒有新增本項 GUI 驗收。
