# 013：博物館製作名單的 Noto 呈現

狀態：限定 CONFORMED。五次字幕的正常來源、呈現、存讀與回退已驗證；最後補齊退休衛式，三項測試及標題 Esc 視窗回歸亦通過。範圍為正常開場的四組製作名單，共五次繪字。沿用已批准的 Noto Black 900、原文、位置與出場順序。後續 [017](017-intro-museum-art.md#正式接入與限定驗收)已接入館景、人物與光束，字幕仍最後覆繪；新視窗的 Noto／草書四組名單另經逐 RGBA 回歸。本規格早期原版美術收據保持。

## 已證實來源

工具、原版 EXE／PAM、執行期輸入、字碼及字模 SHA 同 [012](012-intro-story-noto.md)。證據位於 `workplace/probe-20261023/graphics-first/captions-r1/`。IDA 9.4 讀正式資料庫的唯讀副本，`ida-pages-r1.json` 保留原名、位址、bytes 及交叉參照；以下為執行期線性位址，不是壓縮 EXE 偏移。

- 正常 VGA／AdLib 冷啟動的 `trace-r2/calls.jsonl` 共五次 `sub_58B1`。來源為 DS 0B31:0042／006A／0092／00BA／00BA，每筆固定 40 bytes。完整 160 bytes SHA `2689f07c2dde43c039c216e1417276616c12bf824f50dfbd79590f5a88509a44`。零結尾前長度分別 33／25／19／25／25 bytes，保留原版字形與空格，不依人名印象改寫。
- 五次參數皆為 `[來源,0,160]`，前景色 3、背景值 FF。返回位置為 1C81／1C9A／1DBB／1E4E／1EB0。CJK 及 ASCII 空格沿用 012 的實際 consumer；CJK 占兩個 bytes，空格占一個，各 byte 對應八個原生像素。
- 每次目的頁字幕區都是黑底。DS:1EF8 為 A400／A000／A000／A400／A000，對應 VGA 實體平面偏移 4000h 或 0。字型列位址表從 0231:2AC4 起，每列 80 bytes；字幕 y=160 至 174。不能把當前可見頁當作繪字目的頁。
- `sub_5DC2` 選繪圖段；`sub_5E06` 選顯示頁。`sub_2246` 依序選兩頁。`sub_5D76`／`sub_5D9C` 分派頁面複製，在目前模式的 far return 分別為 5D8F／5DB5；真正清頁為 `sub_5B0C`。`MUSEUM-PAGE-COPY-RESOLVED`：詳見 [017 的方向與完整頁驗證](017-intro-museum-art.md#museum-page-copy-resolved原型清頁誤分類勘誤)。一般清畫面及圖片繪圖的 begin／return 同 011。
- 正常 `sub_1BE2` 在 203C 返回。`source-audit-r1.json` 用原字碼、字模及色盤獨立重建五份目的頁 y160–174 全幅 640×15 區域，逐 RGB byte 同正常原版緩衝區；不是只看字串表。目的頁截圖是診斷，不冒充真正視窗。

## 呈現契約

1. 重用 r11 已驗證的 448 字集，沒有新資產或字型方向。缺少或損壞該 atlas 時，字幕與故事回原字，標題、PAM Noto、圖像及音樂保持原有回退契約。原文與字型資產仍只留本機。
2. 只有固定程式窗、0B31 資料段、160-byte 原文、353 字碼／字模及既知呼叫者皆吻合才啟用。首個入口為 1BE2；203C、1322 或 PAM 後永久退休，不能把相同位址套到另一程式。
3. 字幕按 VGA 實體頁保存。僅在 640×200、pitch 80、顯示 start 為 0／4000h、line-compare 不切畫面時呈現該頁的字幕。原矩形為 `(0,160)-(原文 bytes×8,175)`，最寬 264 像素；放大後先還原已證實黑底，再於每字安全矩形畫 Noto，空格仍占原寬度。原色取目前呈現色盤的 3，不套用故事金色。
4. 原版字串繪圖中可先呈現完整字幕，背景頁仍不可見。清頁／一般圖片交易中若改寫字幕區，字幕持續至該交易最外層返回後失效，避免殘留原字。交易等待上限 2000000 客體 cycles，逾時記錄並回原版，不阻塞 DOS、輸入或音訊。其他未知寫入使該字幕失效；模式或幾何不符回原版。
5. Engine 同次轉送既有視訊 callback 給 Tracker、標題、故事與字幕，不能另訂閱覆蓋前者。覆繪前複製共享底圖，Frame 及所有觀測不寫客體。來源收據保存當時可見頁與目的頁；前端另記錄來源請求、實際合成、退休、失效及故障，Draw 來源取自同一個實際 frame。

## 驗收

- 五次來源、四組名單、兩個實體頁及原字模像素核對；r11 全部 56 檔保持不變。
- 正常冷啟動看完四組名單與頁切換，再自然進入五頁故事、PAM、新遊戲、F1、返回與 F7。另在字幕普通 Esc，完成真正存退讀。
- 同輸入及虛擬時間的原字幕／Noto 完整客體、工作檔、事件及音訊相同。Frame 前後完整 state 相同。其餘音畫兩側沿用 r11，差異範圍只限字幕。
- 真實壞 atlas 回原字並保留其他 HD；失去 return 有界回退。真正視窗與連續幀檢視原字首露、殘字、翻頁與清除，四組字幕皆需實際可見。

證據足夠後停止深入字庫與通用清頁 helper。此規格不宣稱其餘片頭美術、其他文字或全遊戲完成。
