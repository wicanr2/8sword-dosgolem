## DRAFT 時的必要證據

- 由既有固定 DOS 時鐘、普通新遊戲與第一場自然遭遇取得四筆完整返回、目的矩形、進場前後索引與還原呼叫，不用直接進場或注入。

- HD 火花須與原版／HD 部隊及 Noto 共存。資料 → 來源識別 → 正常戰場 → 圖層／還原 → 返回地圖 → F1／F2 → 真正存退讀，不能只做四張貼圖。
