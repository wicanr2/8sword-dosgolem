## 載入與呈現契約

可重現匯入入口：[民兵素材工具](../../tools/prepare-hd-army.py)。在既有 Pillow 容器內指定 `--base` 為 r15、`--source` 為 `MAN01.EGG`、`--art` 為保存的原始生成圖、`--prompt` 為完整提示，`--out` 為存在且空白的輸出目錄。工具核對固定來源，保留舊檔，輸出原始 PNG、更新的清單及本機權利紀錄。

- 沿用 `terrain.json` schema 1 的 `actors`。來源索引 72..83 保留主角，84 專供已證實的民兵記錄；最多十三筆，不增加清單欄位。不含 84 的舊組不增原版來源，保持既有目錄及取樣像素。
- 索引 84 存在才增加原版來源 84，ID 85。寬 11 bytes、高 50，前四平面及完整六塊指紋固定如上。不得用同尺寸或相似圖片推定其他兵種。
- 圖片仍驗檔名、SHA、尺寸、PNG、透明背景及不透明主體，`sampling` 必須為 `bitmap`，不接受裁幅。原始生成 PNG 不改 byte；雙線性預乘 alpha 快取為 264×300，主角仍 192×150。低 alpha 的處理沿用 007。
- 民兵輪廓沿用已批准的 B 畫風及原版藍背心、白褲、青頭巾與持槍方向。這是刻意美化，不稱逐像素原版相同。生成原圖、提示、來源雜湊與本機散布限制同次保存。
- 只有六塊記錄指紋及整幅底圖所有權有效才開始人物交易。允許的尺寸限 64×25 或 88×50。每個所有權格記錄自身圖像寬高導出的座標，不沿用主角常數。
- 四平面寫入完成後保留原底圖所有權，先重畫玉紙，再合成民兵，再合成 Noto。原版像素與字墨不改。每次位元組寫入、搬移、同值寫入與模式清除的失效沿用 007。
- PNG 缺失、尺寸／SHA 不符或清單錯誤時整組圖像拒用，Noto、獨立片頭及音樂依既有契約運行。未知原版記錄、缺底圖或未完成交易採原圖，不偽造民兵。第十三張 PNG 失敗也不可留下已載入的十二張主角。
- 正式載入只讀資料，無新 DOS 寫入、規則、選單或存檔欄位。建置前的 44 筆來源及四個程式存 `workplace/player/build-pre-army-r1/`，以 `bd6a6810…b7` 回查歷史收據。

## 驗收範圍

原始圖片 → 固定指紋及 HD PNG → 正常 F2 → 返回地圖 → F1／F2 再進入 → 真正存退讀。須證明新圖實際啟用、Noto 字色及位置保持、原版身形不殘留、來源或 PNG 壞掉時可回原版。缺背景、未知來源或幾何不能猜補。

本規格只處理正常新遊戲已有的民兵圖，其他兵種、戰鬥與全遊戲 HD 另行驗證。原版與生成候選留本機，正式狀態以後續證據為準。
