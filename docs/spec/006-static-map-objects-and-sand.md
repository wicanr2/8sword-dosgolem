## 透明靜物

- 三張 PNG 由內建 image_gen 以各自原版圖塊為編修目標、批准 B 為樣式參考，保留構圖與朝向，新增手繪細節及柔和投影。它們不含草地底或文字。原圖及提示留本機，來源與 SHA 見 `graphics-first/generated-art-r3.json`，不改動 PNG bytes。
- `terrain.json` 新增 `overlays`，每筆包含來源索引、PNG 檔名、SHA、實際尺寸及 `background_source=0`。只允許 50／53／57；背景必須是已直接載入的草地 0，不能依賴合成項或重複其他來源。
- 來源原版是五組不透明圖塊，因此可以將新物件的透明像素預先合成於 HD 草地，產生不透明 192×150 快取。這個草底是批准畫風內的視覺重繪，不宣稱逐像素還原原版草紋。
- 新 PNG 須有透明及不透明像素；雜湊、實際尺寸及容量沿 004 檢查。讀入後按整張畫布雙線性取樣，不裁去原有透明邊距，以保留圖塊內位置。三張新圖的外緣雜訊 alpha 至多為 1；取樣端點 alpha 0–3 視為全透明，其餘保留。這只影響呈現，不改生成原圖。
- 以預乘 alpha 的四個端點插值，再加 `背景 × (1-alpha)`，不能重複乘 alpha。快取所有像素 alpha 固定為 255；透明區必須與 HD 草地相同，不能成為黑底或放大原版圖塊。
- 保持既有真正寫入、遮擋、頁搬移、同值失效及模式清除。原版角色仍透過其第六組遮罩覆蓋靜物；這條靜物路徑不涵蓋生成角色的背景還原。

## 黃色地表

- 直接材質來源為 30，取新生成 `sand-painted-r1.png` 中心 512×400，套用既有取樣與對邊漸混。31 不是純底，45 不是本規格的過渡，不得依連續索引猜補。
- 合成規則為 `pmap-grass-sand-v1`，僅允許索引 31–44，`land_source=0`、`sand_source=30`，其他依賴值為 0。草地色碼 2／10 投正票，黃色地表的 7／12／13／15 投負票，0／1／8／9／14 不投票。沿用 004 的 7×3 權重、0.4–0.6 柔化與 x3／y6 取樣，無票時取黃色地表；未知色碼拒用。
- 色群柔化與新材質是刻意美化，不是原版地形分類或透明遮罩。規則不得影響碰撞、事件、亂數與存檔。

## 審查與驗收

READY 前核對上述偏移、來源指紋、色碼集合、透明 PNG、取樣公式與依賴。不能由像素少或檔名直接猜地圖功能。

審查結果：原版每筆形狀 64×25 及五組不透明契約沿 004 已證實；來源四色平面與完整記錄指紋逐筆核對。三張生成 PNG 均有 alpha 0 與 255，外緣至多為 1，允許上述 alpha 0–3 處理。原版既有正常重播實際呼叫 50／53／57 分別 4／10／6 次，沒有呼叫 30–44；故本輪不得由同一重播宣稱沙地正常場景完成。

- 用真實 PNG 驗證透明、全不透明、半透明及投影，檢查預乘 alpha、原始邊距與不透明快取。錯誤背景、來源、重複或損壞必須整組拒用，Noto 保留。
- 舊 35 筆素材組的保存畫面不變；新組需真正顯示三種靜物，不能只看素材數量。正常視窗冷啟動、新遊戲、移動、人物頁往返及真正存退讀，檢查草底接合與遮擋。
- 同輸入下比較完整客體狀態、輸入、載入事件與 DOS 工作檔。沒有正常玩家路徑看到的黃色地表，只能記為已製作與載入，不稱正常場景驗收完成。
- 新組合計 53 筆：六張直接材質、41 筆地表合成、三張靜物及三筆介面；其他圖像、角色動畫、HD 音樂與效能仍未完成。
